# Premiere Pro 編集をコンピューターユーズで頼むためのフォルダ

```
my-project/                       ← 「Claude Code/」フォルダにあたる
├── CLAUDE.md                     ← 共通ルール（進め方マニュアルの場所も書く）
├── 動画編集/
│   └── 編集の進め方マニュアル.md
└── 案件データ/
    ├── _テンプレート/            ← 新しい会社はここをコピー
    │   ├── CLAUDE.md
    │   └── 案件マニュアル.md
    └── A社/
        ├── CLAUDE.md
        ├── 案件マニュアル.md
        └── A社_デザインシーケンス.prproj   ← 自分で置く
```

## 使い方

1. このフォルダを **Premiere Pro が入っているパソコン** に置く（`git clone` またはダウンロード）。
2. `案件データ/A社/` に `A社_デザインシーケンス.prproj` を置き、`案件マニュアル.md` の（例）を実際の内容に書き換える。
3. Claude デスクトップアプリでこのフォルダを開き、コンピューターユーズを有効にする（Premiere Pro へのアクセスを許可）。
4. 次のように頼む：

```
案件データ/A社 の案件を編集して。
CLAUDE.md と進め方マニュアルの順番どおりに、Premiere Pro をコンピューターユーズで操作して進めてください。
書き出しはしないで、終わったら報告して。
```

## 新しい案件を増やすとき

`案件データ/_テンプレート` を `案件データ/<会社名>` としてコピーし、`<会社名>` を置き換え、デザインシーケンスの .prproj を置く。
