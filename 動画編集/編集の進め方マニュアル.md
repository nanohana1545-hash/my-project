# 編集の進め方マニュアル（全案件共通）

Claude はこの順番どおりに進める。各ステップの「完了条件」を満たしたら次へ進む。
案件ごとの判断は `案件データ/<会社名>/案件マニュアル.md` を見る。

---

## STEP 0. 準備

1. `案件データ/<会社名>/CLAUDE.md` と `案件マニュアル.md` を読む。
2. 素材フォルダの場所（案件マニュアルに記載）を確認する。
3. Premiere Pro を起動し、案件マニュアルに書かれた **作業用プロジェクト** を開く。
   - 作業用プロジェクトがまだ無い場合：新規プロジェクトを作り、`<会社名>_編集_YYYYMMDD_v01.prproj` で保存する。

**完了条件**：作業用プロジェクトが開いていて、別名で保存されている。

## STEP 1. 素材の読み込み

1. `Cmd+I`（読み込み）で、案件マニュアルの「素材フォルダ」から動画・音声を読み込む。
2. プロジェクトパネルに `01_素材` ビンを作り、読み込んだ素材を入れる。

**完了条件**：`01_素材` ビンにすべての素材がある。

## STEP 2. デザインシーケンスからパーツを持ってくる

1. `Cmd+I` で `案件データ/<会社名>/<会社名>_デザインシーケンス.prproj` を選ぶ。
2. 「Premiere Pro プロジェクトの読み込み」ダイアログでは **「選択したシーケンスを読み込み」** を選び、案件マニュアルの「使うパーツ」に書かれたシーケンスだけを読み込む。
3. 読み込まれたものを `02_デザイン` ビンにまとめる。
4. デザインシーケンスの元 .prproj は開いたり上書きしたりしない。

**完了条件**：`02_デザイン` ビンに、案件マニュアルで指定されたパーツがそろっている。

## STEP 3. シーケンスを作る

1. 案件マニュアルの「シーケンス設定」（解像度・フレームレート）に合わせて新規シーケンスを作る。
   - 一番簡単なのは、デザインシーケンス内の「ベース」シーケンスを複製して名前を変える方法。
2. 名前は `<会社名>_本編_YYYYMMDD`。

**完了条件**：正しい設定のシーケンスがタイムラインに開いている。

## STEP 4. 素材を並べる（粗編集）

1. 案件マニュアルの「構成」の順番で、`01_素材` からタイムラインの V1/A1 に並べる。
2. 案件マニュアルの「カットのルール」に従って不要部分をカットする（`C` レーザー → 不要部分を選んで `Shift+Delete` でリップル削除）。
3. ルールで判断できない箇所はカットせず、マーカー（`M`）を打ってコメントに理由を書く。

**完了条件**：構成どおりに並び、迷った箇所にはマーカーがある。保存（`Cmd+S`）。

## STEP 5. パーツを配置する

案件マニュアルの「使うパーツ」表に従い、`02_デザイン` からトラックに配置する。

| トラック | 入れるもの（基本） |
|---|---|
| V1 | 本編映像 |
| V2 | ワイプ・差し込み映像 |
| V3 | テロップ |
| V4 | ロゴ・タイトル |
| A1 | 本編音声 |
| A2 | 効果音 |
| A3 | BGM |

- テロップは、デザインシーケンスのテロップクリップを **コピーして文字だけ書き換える**（フォント・色・位置は触らない）。
- 文字の書き換えはエッセンシャルグラフィックスパネル、またはプログラムモニター上でテキストツール（`T`）を使う。

**完了条件**：案件マニュアルで指定されたパーツがすべて配置されている。保存。

## STEP 6. 音の調整

1. 案件マニュアルの音量基準に合わせる（例：声 -6dB 前後、BGM -24dB 前後）。
2. BGM は最初と最後にフェード（オーディオトランジション「コンスタントパワー」）。

**完了条件**：音が割れていない・BGMが声を邪魔していない。保存。

## STEP 7. 最終チェックと報告

1. 先頭から再生し、案件マニュアルの「チェックリスト」を1つずつ確認する。
2. `Cmd+S` で保存し、必要なら `_v02` で別名保存。
3. 共通ルール（`/CLAUDE.md`）の形式で報告する。**書き出しは指示があるまでしない。**

## よく使うショートカット（Mac / Windows）

| 操作 | Mac | Windows |
|---|---|---|
| 保存 | Cmd+S | Ctrl+S |
| 別名で保存 | Cmd+Shift+S | Ctrl+Shift+S |
| 読み込み | Cmd+I | Ctrl+I |
| 新規ビン | Cmd+B | Ctrl+B |
| 新規シーケンス | Cmd+N | Ctrl+N |
| 選択ツール / レーザーツール / テキストツール | V / C / T | V / C / T |
| 再生ヘッド位置でカット | Cmd+K | Ctrl+K |
| リップル削除 | Shift+Delete | Shift+Delete |
| マーカー追加 | M | M |
| 再生 / 停止 | Space | Space |
| 取り消し | Cmd+Z | Ctrl+Z |
| タイムライン全体表示 | \ | \ |
